# Dip-rebound backtest

Question: do S&P 500 / S&P 400 stocks that fall 2% or more on heavy volume
bounce over the next 1-5 sessions? This is the premise behind the evening
"score the decliners" prompt, tested with price data alone before any AI
research is added.

## Run it

```bash
pip install yfinance pandas numpy pyarrow lxml requests
python fetch_data.py        # ~2 min: universe from Wikipedia, prices from Yahoo (2004 onward)
python backtest.py          # ~1.5 min: event study, rule search, portfolio simulations
python export_dashboard.py  # CSVs for the dashboard
```

`data/` and `results/events.csv.gz` are regenerated by the scripts and not committed.

## Setup

| | |
|---|---|
| Universe | 903 current S&P 500 + S&P 400 members, counted only from the date each joined an index where known |
| Signal | close-to-close return <= -2%, volume >= 1M, unadjusted close >= $20 |
| Entry / exit | buy at the next open, sell at the close 1, 2, 3 or 5 sessions later |
| Edge | signal return minus the average of all eligible stocks over the same window, date-clustered t-stat |
| Fair test | rules chosen on 2005-2015, judged on 2016-2026 |
| Costs | 5 bps per side (also 0 and 10) |

## Results (Jan 2005 - Oct 2026, 179,301 signals)

| Hold | Raw return after dip | Same stocks, any day | Edge vs same-day stocks | t-stat |
|---|---|---|---|---|
| 1 day | +0.10% | +0.02% | -0.01% | -0.77 |
| 3 days | +0.29% | +0.13% | +0.02% | 0.78 |
| 5 days | +0.47% | +0.23% | +0.01% | 0.27 |

1. **No edge in the plain screener.** The raw bounce is the market bouncing
   (crash days produce hundreds of signals that all rebound together).
   Against stocks bought the same morning, the edge is zero.
2. **The rule search overfit.** The top rule on 2005-2015 ("prior 5 days down
   + sector flat/up") had a +0.27% edge, t = 3.5. On 2016-2026 it was -0.01%.
3. **Conditions that held up best in both periods** (leads, not proof, since
   they were seen after the out-of-sample data):
   stock already down 5%+ over the prior 5 days, the S&P down 1%+ that day,
   and the S&P below its 200-day average. All point to *oversold during
   broad selling*, not single-stock bad news.
4. **Costs decide it.** All dips, 3-day hold: 8.5% a year before costs,
   0.9% after 5 bps per side, vs 10.9% for SPY. Every SPY-hedged version
   loses money.
5. **Known bias:** delisted and acquired stocks are missing (Yahoo keeps no
   history), which flatters dip buying. Real results would likely be worse.

## What this means for the evening prompt

Price data alone gives the AI nothing to build on, so any value has to come
from the research (news, guidance, peer read-through). That can be measured:
log each night's scores, then compare next-day returns of high vs low
composite scores with the same edge metric used here.

## Holdout test of the oversold lead (pre-registered)

The rule and pass criteria were committed in `PREREGISTRATION.md` before any
holdout prices were downloaded. Holdout: 835 US stocks over $2B that are not
in the S&P 500/400 (`results/holdout_universe.csv`). Run with
`python holdout.py`; results in `results/holdout.json`.

| Rule (3-day hold) | Signals | Edge | t-stat | 2005-15 | 2016-26 | Raw 3-day | Win rate |
|---|---|---|---|---|---|---|---|
| H1: prior 5 days down 5%+ and SPY down 1%+ | 5,677 | +0.08% | 0.56 | -0.01% | +0.15% | +1.11% | 57.5% |
| H2: prior 5 days down 5%+ | 15,194 | +0.02% | 0.20 | +0.23% | -0.08% | +0.50% | 52.5% |
| H3: SPY down 1%+ | 19,883 | +0.01% | 0.19 | -0.05% | +0.08% | +0.46% | 53.7% |
| H0: every dip | 65,141 | +0.05% | 1.12 | +0.01% | +0.08% | +0.19% | 50.9% |

**Verdict: H1 fails.** It misses criterion 1 (t = 0.56, needed 2.0) and
criterion 2 (negative in 2005-2015). It passes criterion 3 only barely
(+1.5% a year after costs, vs 10.9% for SPY). The same H1 rule on the
original S&P 500/400 stocks was also weak (edge +0.09%, t = 0.78). Its
parts, H2 and H3, looked real there (t = 2.4 and 2.8) but show nothing on
the holdout.

The +1.1% raw return and 57.5% win rate for H1 look attractive, but they
come from buying on market-wide selloff days that tend to rebound. Other
stocks bought those same mornings did about as well. That's market timing
with leverage to the bounce, not a dip-specific edge.

**Conclusion:** there is no price-only edge here worth building on. The
lead was a product of searching many splits on one set of stocks.
